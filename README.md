# Data Analytics Portfolio

A practical portfolio of **data analysis, business intelligence, SQL, Python, data cleaning, and dashboard projects**.

The portfolio follows a simple standard: **data → analysis → KPI → business insight → deliverable**.

## Portfolio Focus

- Exploratory and diagnostic data analysis
- Business KPI and trend analysis
- SQL-based business intelligence
- Data cleaning and validation
- Customer and workforce segmentation
- Revenue, profitability and marketing analytics
- Dashboard-oriented reporting
- Reproducible Python workflows

## Technical Stack

**Python:** Pandas, NumPy, Matplotlib  
**SQL:** SQLite, CTEs, window functions, joins, aggregation, ranking  
**Visualization:** Matplotlib, HTML, JavaScript, Chart.js  
**Workflow:** Jupyter Notebook, reusable Python scripts, JSON outputs

## Repository Standards

Each project is organized around:

1. A clear business question
2. Documented data provenance and assumptions
3. A reproducible notebook and/or script
4. Meaningful outputs and visualizations
5. Business-oriented interpretation
6. Clear separation of notebooks, source code, data, SQL, dashboards and outputs

Synthetic datasets are explicitly identified where applicable. Synthetic results are demonstrations of analytical technique and are not presented as real company performance.
