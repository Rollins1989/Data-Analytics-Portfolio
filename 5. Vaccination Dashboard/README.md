# Global Vaccination Dashboard

## Business Objective

Analyze global vaccination data and communicate geographic and temporal patterns through KPI-focused visualizations.

## Focus Areas

- Global vaccination trends
- Geographic comparisons
- KPI-oriented reporting
- Time-series analysis
- Visual communication of public-health data

## Business Interpretation

The project demonstrates how a large public-health dataset can be transformed into concise KPIs and visual comparisons designed for decision-oriented reporting.

## Tools

**Python · Pandas · Jupyter Notebook · Data Visualization**

## Files

- `vaccination_analysis.ipynb` — analysis notebook
- `vaccination_analysis.py` — analysis script
- `vaccination_dashboard.png` — dashboard output
- `vaccination_analysis_output.png` — notebook output

## How to Run

From the project directory:

```bash
python vaccination_analysis.py
```

Or open `vaccination_analysis.ipynb` in Jupyter Notebook/JupyterLab and run the cells from top to bottom.

## Skills Demonstrated

Data preparation, aggregation, trend analysis, comparative visualization, KPI reporting, dashboard communication, and analytical storytelling.
