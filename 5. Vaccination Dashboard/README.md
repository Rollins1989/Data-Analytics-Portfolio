# Global Vaccination Dashboard

## Overview

A visualization-focused project analyzing global vaccination data and presenting the results through a dashboard-oriented output.

## Focus Areas

- Global vaccination trends
- Geographic comparisons
- KPI-oriented reporting
- Visual communication of public-health data

## Tools

- Python
- Pandas
- Jupyter Notebook
- Data visualization

## Files

- `Project 5.ipynb` — analysis notebook
- `vaccination_dashboard.png` — dashboard output
- `Project 5_output (1).png` — notebook output

## Skills Demonstrated

Data preparation, aggregation, trend analysis, comparative visualization, KPI reporting, and dashboard communication.

## How to Run

Open `Project 5.ipynb` in Jupyter Notebook or JupyterLab and run the cells from top to bottom.
