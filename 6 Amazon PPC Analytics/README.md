# Amazon PPC Analytics Dashboard

## Overview

An advertising analytics project focused on Amazon PPC campaign performance, spend allocation, and weekly campaign trends.

## Focus Areas

- Campaign performance
- Advertising spend allocation
- Weekly trends
- Performance KPI reporting
- Interactive dashboard presentation

## Tools

- Python
- HTML
- JavaScript
- Chart.js

## Files

- `amazon_ppc_dashboard.html` — interactive dashboard
- `campaign_performance.xls` — campaign data
- `spend_allocation.xls` — spend allocation data
- `weekly_trends.xls` — weekly trend data
- `Project 6.ipynb` — notebook placeholder
- `Project 6_output (1).png` — output image

## Important Note

The interactive dashboard is currently the primary deliverable for this project. The notebook is not yet a substantive analysis notebook and should not be presented as one until it is rebuilt.

## Skills Demonstrated

Campaign KPI analysis, advertising performance analysis, spend allocation, trend reporting, and interactive dashboard development.
